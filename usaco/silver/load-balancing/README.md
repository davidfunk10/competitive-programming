## Load Balancing (USACO Silver)

For this complete search problem, I initally thought of looping through every single possible pair of east-west and south-north fences and check the number of cows in each quadrant created. However, I soon found out that the time complexity for that was much too slow. Then, I realized I could take a more efficient "sliding window" approach. Basically, I looped through every possible east-west line and moved a vertical line horizontally across the graph after each new x coordinate in the `cows` vector. This way I could skip the process of looping through unneccessary lines and cut back on the time complexity, becoming `O(n^2)`. Using the hozizontally sliding vertical line, I populated an `abovebelow` vector that I later looped through to find the lowest possible division with any two north-south and east-west lines that actually matter. In short, I skipped over the gaps of x values to cut down on the time complexity to solve this problem. This problem made me think through time complexity more deeply and come up with a more efficient solution than just general complete search.
